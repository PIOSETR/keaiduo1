安装 喵喵听写

选择最适合你的方式

📦 下载 APK

适用于所有安卓手机（Android 5.0+）

⬇️ 下载 APK 安装包 约 1-2 MB · 直接安装即可
📱 用手机扫码下载

📖 安装步骤

1
下载 APK点击上方按钮或扫码下载安装包
2
允许安装未知应用安卓会提示"禁止安装未知来源应用"→ 点击"设置"→ 打开"允许安装"
3
点击安装安装完成后即可在桌面打开「喵喵听写」🐱

🌐 添加到主屏幕

无需下载安装包，像 App 一样使用

🏠 打开 喵喵听写 然后按下面的步骤添加到主屏幕

📖 各浏览器设置步骤

🌐
Microsoft Edge
1. 点击底部菜单栏 「···」（更多）
2. 选择 「添加到手机屏幕」
3. 点击 「添加」 即可在主屏幕看到图标
▶️
Google Chrome
1. 点击右上角 「···」（菜单）
2. 选择 「添加到主屏幕」
3. 点击 「添加」
📱
其他浏览器（UC / 夸克 / 华为等）
1. 点击浏览器底部或顶部的 「菜单」
2. 找到 「添加到主屏幕」 或 「添加到桌面」
3. 确认添加即可
